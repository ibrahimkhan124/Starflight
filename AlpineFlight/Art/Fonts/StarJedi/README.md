# Star Jedi

Star Jedi by Boba Fonts. Downloaded from https://www.dafont.com/star-jedi.font
on 10 October 2026. The source page labels the font “100% Free”.

The unmodified base font is bundled at `AlpineFlight/Resources/Fonts/Starjedi.ttf`.
Its PostScript name is `StarJedi`. The original author’s Word font guide is
preserved beside this file for attribution and character usage information.

The app registers the font once at launch and uses `FlightStyle.displayFont`
for display text. Small numerical flight instruments and explanatory paragraphs
retain system fonts for readability.
